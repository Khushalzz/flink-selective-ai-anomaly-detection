# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in BDT, please report it responsibly:

- Do **not** open a public GitHub issue.
- Please email security findings to the maintainer or report via GitHub Security Advisories.
- Include detailed steps to reproduce the issue, along with affected versions and environment details.
- We will acknowledge receipt of your vulnerability report within 48 hours and work with you on a timely resolution.
